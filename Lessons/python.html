🔵 1. Introduction to Python

Python is a high-level, general-purpose programming language known for readable syntax and a large ecosystem of libraries.

Where is Python used?

🌐 Web Development
Build websites and web applications.
🤖 AI & Machine Learning
Work with intelligent systems and models.
📊 Data Science
Analyze and visualize data.
⚙️ Automation
Automate repetitive tasks.
🔐 Cybersecurity
Write tools and scripts for security work.
🎮 Games & Apps
Create programs and prototypes.

Why is Python beginner-friendly?

  • Simple and readable syntax.
  • Large collection of built-in functions and libraries.
  • Works on Windows, macOS and Linux.
  • Large developer community and learning resources.
  • Supports procedural, object-oriented and other programming styles.
Study tip: Don't try to memorize Python. Understand a concept, type the code yourself, change it, and observe the output.

🔵 2. Python Syntax & Your First Program

Syntax means the rules for writing valid code.

print("Hello, World!")

Output:

Hello, World!

print()

print() displays information on the screen.

print("Hello")
print("Welcome to Python")
print(10)

Comments

Comments explain code and are ignored during normal execution.

# This is a single-line comment
print("Python")
Important: Python uses indentation (spaces at the beginning of a line) to define code blocks. Be consistent, commonly using 4 spaces.

🔵 3. Variables & Data Types

A variable is a name that refers to a value.

name = "Tanvi"
age = 20
marks = 87.5
is_student = True

print(name)
print(age)

Basic data types

Type Example Meaning
int 20 Whole number
float 87.5 Decimal number
str "Python" Text
bool True True/False value
NoneType None No value / absence of a value

Checking a type

x = 25
print(type(x))

Variable naming rules

  • Can contain letters, numbers and underscores.
  • Cannot begin with a number.
  • Cannot contain spaces.
  • Cannot use Python keywords such as if, for or class.
  • Names are case-sensitive: age and Age are different.
Good: student_name, age2, total_marks
Bad: 2age, student name

🔵 4. Taking Input & Type Conversion

The input() function takes input from the user. It returns text (a string).

name = input("Enter your name: ")
print("Hello", name)

Taking numbers

age = int(input("Enter your age: "))
height = float(input("Enter your height: "))

print(age)
print(height)

Type conversion

Function Purpose Example
int() Convert to integer int("25")
float() Convert to decimal float("2.5")
str() Convert to string str(25)
bool() Convert to Boolean bool(1)
Common beginner mistake: input() gives a string. So input() + input() joins text instead of doing numeric addition unless you convert the values.

🔵 6. Conditional Statements

Conditions allow a program to make decisions.

if

age = 20

if age >= 18:
    print("Adult")

if-else

age = 16

if age >= 18:
    print("Adult")
else:
    print("Minor")

if-elif-else

marks = 75

if marks >= 90:
    print("Grade A")
elif marks >= 60:
    print("Grade B")
elif marks >= 40:
    print("Grade C")
else:
    print("Fail")
Remember: The colon : starts the block, and the indented lines belong to that block.

🔵 7. Loops

Loops repeat code. Python's main loops are for and while.

for loop

for i in range(1, 6):
    print(i)

Output: 1 2 3 4 5

Understanding range()

range(stop)
range(start, stop)
range(start, stop, step)

The stop value is excluded.

for i in range(2, 11, 2):
    print(i)

Output: 2, 4, 6, 8, 10

while loop

i = 1

while i <= 5:
    print(i)
    i += 1
Infinite loop warning: In a while loop, make sure something changes so the condition eventually becomes false.

break

for i in range(1, 10):
    if i == 5:
        break
    print(i)

continue

for i in range(1, 6):
    if i == 3:
        continue
    print(i)

🔵 8. Strings

A string is text enclosed in quotes.

name = "Python"

Indexing

text = "Python"

print(text[0])   # P
print(text[1])   # y
print(text[-1])  # n

Slicing

text = "Python"

print(text[0:3])   # Pyt
print(text[2:])    # thon
print(text[:4])    # Pyth

Useful string methods

text = "hello python"

print(text.upper())
print(text.lower())
print(text.title())
print(text.replace("python", "world"))
print(text.split())

f-strings

f-strings are a convenient way to insert variables into text.

name = "Tanvi"
age = 20

print(f"My name is {name} and I am {age} years old.")

🔵 9. Collections: List, Tuple, Set & Dictionary

List

A list stores multiple values and is mutable (changeable).

fruits = ["Apple", "Mango", "Banana"]

print(fruits[0])

fruits.append("Orange")
fruits.remove("Mango")

print(fruits)

Useful methods: append(), remove(), pop(), sort(), reverse().

Tuple

A tuple is an ordered collection that is generally used when values should not be changed.

colors = ("Red", "Blue", "Green")
print(colors[1])

Set

A set stores unique values and does not use normal positional indexing.

numbers = {1, 2, 2, 3, 4}
print(numbers)  # duplicate 2 is stored only once

Dictionary

A dictionary stores data as key-value pairs.

student = {
    "name": "Tanvi",
    "age": 20,
    "course": "BCA"
}

print(student["name"])
student["age"] = 21
Collection Ordered? Changeable? Duplicates?
List Yes Yes Yes
Tuple Yes No Yes
Set No positional indexing Yes No
Dictionary Insertion order preserved Yes Keys are unique

🔵 10. Functions

A function is a reusable block of code.

Creating a function

def greet():
    print("Hello!")

greet()

Parameters

def greet(name):
    print("Hello", name)

greet("Tanvi")

Return value

def add(a, b):
    return a + b

result = add(10, 20)
print(result)

Default parameter

def greet(name="Student"):
    print("Hello", name)

greet()
greet("Tanvi")
Why use functions? They reduce repetition, organize programs, make code easier to test, and improve readability.

🔵 11. Errors & Exception Handling

Common errors

  • SyntaxError: Code does not follow Python syntax.
  • NameError: A variable or name is not defined.
  • TypeError: An operation is used with an inappropriate type.
  • ValueError: A value has the right general type but an invalid value.
  • ZeroDivisionError: Attempting to divide by zero.

try-except

try:
    number = int(input("Enter a number: "))
    print(10 / number)
except ValueError:
    print("Please enter a valid integer.")
except ZeroDivisionError:
    print("Cannot divide by zero.")

Exception handling lets your program respond to expected runtime problems instead of crashing immediately.

🔵 12. Modules & Libraries

A module is a Python file containing reusable code. Python also provides a large standard library and many third-party packages.

Importing a standard module

import math

print(math.sqrt(25))
print(math.pi)

Importing a specific item

from math import sqrt

print(sqrt(49))

Random numbers

import random

number = random.randint(1, 10)
print(number)
Don't memorize every library. Learn how to read documentation and find the correct function when you need it.

🔵 13. File Handling — Basics

Python can read from and write to files.

Writing a file

with open("notes.txt", "w") as file:
    file.write("Python is easy to learn.")

Reading a file

with open("notes.txt", "r") as file:
    content = file.read()

print(content)

Common modes: r = read, w = write/replace, a = append.

🔵 14. Object-Oriented Programming — First Look

Python supports object-oriented programming (OOP). The basic ideas include classes and objects.

Class and object

class Student:
    def __init__(self, name):
        self.name = name

    def introduce(self):
        print("My name is", self.name)

student1 = Student("Tanvi")
student1.introduce()

class defines a blueprint. student1 is an object created from that class. __init__() initializes object data.

🔵 15. Beginner Practice Programs

Program 1 — Add two numbers

a = int(input("Enter first number: "))
b = int(input("Enter second number: "))

print("Sum =", a + b)

Program 2 — Even or odd

number = int(input("Enter a number: "))

if number % 2 == 0:
    print("Even")
else:
    print("Odd")

Program 3 — Largest of three numbers

a = int(input("Enter first number: "))
b = int(input("Enter second number: "))
c = int(input("Enter third number: "))

if a >= b and a >= c:
    print("Largest =", a)
elif b >= a and b >= c:
    print("Largest =", b)
else:
    print("Largest =", c)

Program 4 — Multiplication table

number = int(input("Enter a number: "))

for i in range(1, 11):
    print(number, "x", i, "=", number * i)

Program 5 — Factorial

number = int(input("Enter a positive integer: "))
factorial = 1

for i in range(1, number + 1):
    factorial *= i

print("Factorial =", factorial)

Program 6 — Prime number check

number = int(input("Enter a number: "))

if number < 2:
    print("Not prime")
else:
    is_prime = True

    for i in range(2, int(number ** 0.5) + 1):
        if number % i == 0:
            is_prime = False
            break

    if is_prime:
        print("Prime")
    else:
        print("Not prime")
