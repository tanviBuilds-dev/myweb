🟣 1. What is CSS?

CSS stands for Cascading Style Sheets. It dictates how HTML elements are projected onto screen, print, or other media.

Cascade & Specificity: When multiple rules target the same element, CSS determines which style wins using inheritance, source order, and selector specificity (IDs beat classes, classes beat tag selectors). 
/* Basic CSS Syntax Structure */
selector {
    property: value;
    another-property: value;
}

/* Example: Modern Card */
.feature-card {
    background-color: #ffffff;
    color: #1a202c;
    border-radius: 12px;
    padding: 24px;
    box-shadow: 0 4px 14px rgba(0, 0, 0, 0.08);
}

🟣 2. Selectors and Combinators

CSS provides multiple ways to pinpoint exactly which elements to style:

Selector Example Matches
Element (Type) p { ... } Every <p> element on the page
Class .btn-primary { ... } Elements with class="btn-primary"
ID #mainHeader { ... } The unique element with id="mainHeader"
Descendant nav a { ... } Any link nested anywhere inside a <nav>
Direct Child ul > li { ... } Only immediate <li> children of <ul>
Pseudo-class button:hover, :focus State changes like user hover or keyboard focus

🟣 3. The CSS Box Model

Every HTML element is considered a rectangular box consisting of four layers: Content, Padding, Border, and Margin.

Margin (Outer space around the box)
Border (Visual edge)
Padding (Inner breathing room)
Content (Text, Image, Video)
⚡ Critical 2026 Reset: Always apply box-sizing: border-box globally. This guarantees that padding and border are included inside the element's width, preventing layout overflow surprises! 
*, *::before, *::after {
    box-sizing: border-box;
}

🟣 4. Modern Colors & Typography

CSS supports Hexadecimal, RGB, HSL, and modern wide-gamut formats like OKLCH.

Color Definitions

/* Hex */
color: #673ab7;

/* RGB with alpha transparency */
background: rgba(103, 58, 183, 0.15);

/* Modern HSL (Hue, Saturation, Lightness) */
border-color: hsl(260, 60%, 50%);

Modern Web Typography

body {
    font-family: 'Inter', system-ui, sans-serif;
    font-size: 1rem;       /* 16px root */
    line-height: 1.65;     /* optimal reading */
    letter-spacing: -0.01em;
}

🟣 5. Flexbox (One-Dimensional Layout)

Flexbox excels at laying out items in a single direction (row or column), distributing available space and aligning items effortlessly.

🟣 6. CSS Grid (Two-Dimensional Layout)

CSS Grid enables simultaneous control over rows and columns. It is the premier layout system for dashboards, photo galleries, and multi-column article layouts.

Interactive Grid (grid-template-columns: repeat(3, 1fr);):

1. Column A
2. Column B
3. Column C
/* Auto-responsive card grid without media queries! */
.card-grid {
    display: grid;
    grid-template-columns: repeat(auto-fit, minmax(280px, 1fr));
    gap: 24px;
}

🟣 7. Responsive Web Design & Media Queries

Media queries adapt your styling depending on screen size, orientation, or user preferences (such as dark mode and reduced motion).

/* Mobile-First Baseline: Single column */
.container {
    display: flex;
    flex-direction: column;
}

/* Tablet & Desktop: Switch to two columns */
@media (min-width: 768px) {
    .container {
        flex-direction: row;
        justify-content: space-between;
    }
}

/* User accessibility preference: Reduced Motion */
@media (prefers-reduced-motion: reduce) {
    * {
        animation-duration: 0.01ms !important;
        transition-duration: 0.01ms !important;
    }
}

🟣 8. CSS Custom Properties (Variables)

Custom properties let you declare variables in CSS and reuse them across your entire stylesheet. They can be updated on the fly with JavaScript or media queries!

:root {
    --primary: #512da8;
    --accent: #ff4081;
    --card-radius: 12px;
}

.card {
    border-radius: var(--card-radius);
    border: 1px solid var(--primary);
}

.button-accent {
    background: var(--accent);
}

🟣 9. Transitions and Micro-Animations

Polished micro-animations elevate modern web apps by delivering tactile feedback when users interact with buttons, cards, and navigation.

/* Smooth Button Hover Lift */
.interactive-btn {
    background: #512da8;
    color: white;
    padding: 10px 20px;
    border-radius: 8px;
    border: none;
    cursor: pointer;
    transition: transform 0.2s ease, box-shadow 0.2s ease;
}

.interactive-btn:hover {
    transform: translateY(-2px);
    box-shadow: 0 6px 18px rgba(81, 45, 168, 0.35);
}
