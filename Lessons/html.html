🟠 1. What is HTML?

HTML stands for HyperText Markup Language. It is not a programming language with variables or loops; rather, it is a markup language that defines the architecture, content, and meaning of web documents.

💡 Core Principle: HTML tells the browser what the content is (a heading, a paragraph, a form, an image), while CSS controls how it looks, and JavaScript controls how it behaves.

Elements & Tags

An HTML element starts with an opening tag <p>, contains content, and terminates with a closing tag </p>.

<p>This is a paragraph.</p>

Attributes

Attributes provide extra metadata or settings to elements, placed in the opening tag as name="value".

<a href="https://example.com" target="_blank">Visit</a>

🟠 2. The Modern HTML5 Boilerplate

Every standard HTML document begins with a standardized document scaffold. Here is the canonical boilerplate used across the web:

<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>My First Website</title>
    <link rel="stylesheet" href="style.css">
</head>
<body>
    <h1>Hello, world!</h1>
    <p>Welcome to my web page.</p>
</body>
</html>
Key Directives:
  • <!DOCTYPE html>: Informs browsers to render in standards mode using the HTML5 specification.
  • <meta charset="UTF-8">: Ensures support for all international characters, emojis, and symbols.
  • <meta name="viewport" ...>: Essential for responsive design on mobile screens and tablets.

🟠 3. Text Formatting & Typography

Structuring text properly allows screen readers and search engines to index your content logically.

Tag Purpose Semantic Meaning
<h1> to <h6> Headings <h1> is the primary title (use only one per page). <h2>-<h6> denote subsections.
<p> Paragraph Wraps a block of running prose.
<strong> Strong Importance Semantically indicates high importance or urgency (typically renders bold).
<em> Emphasis Stresses emphasis in spoken words (typically renders italic).
<blockquote> Quotation Denotes a long citation or quoted section from an external source.
<code> & <pre> Code & Preformatted Monospace text; <pre> preserves line breaks and spaces verbatim.

🟠 4. Images & Media Elements

Images are self-closing void elements. They require the src attribute to point to the resource and the alt attribute for accessibility and fallback description.

<!-- Basic Image with Alt Description -->
<img src="hero-banner.webp" alt="Developers collaborating around a workstation" width="800" height="400" loading="lazy">

<!-- Figure with Caption -->
<figure>
    <img src="chart.svg" alt="Year-over-year developer growth graph">
    <figcaption>Figure 1: Global developer community statistics in 2026.</figcaption>
</figure>
🚀 2026 Best Practice: Always include loading="lazy" on below-the-fold images to optimize initial page loading speeds and Core Web Vitals.

🟠 5. Hyperlinks & Site Navigation

Links are created with the anchor tag <a>. They can route to external URLs, local files, page anchors, email addresses, or phone numbers.

Internal & External Links

<!-- Relative link to lesson -->
<a href="../index.html">Return Home</a>

<!-- External secure link -->
<a href="https://w3.org" target="_blank" rel="noopener noreferrer">
    W3C Standards
</a>

Anchor Links & Actions

<!-- Jump to element with id="forms" -->
<a href="#forms">Jump to Forms</a>

<!-- Email / Telephone trigger -->
<a href="mailto:team@codepath.org">Contact</a>
<a href="tel:+18005550199">Call Us</a>

🟠 6. Lists and Tables

Lists

Unordered (bulleted) with <ul> or ordered (numbered) with <ol>:

<ul>
    <li>Semantic markup</li>
    <li>Cascading styles</li>
    <li>Dynamic scripting</li>
</ul>

Structured Tables

Use <table>, <thead>, <tbody>, <tr>, and <td>:

<table>
  <thead>
    <tr><th>Language</th><th>Role</th></tr>
  </thead>
  <tbody>
    <tr><td>HTML5</td><td>Structure</td></tr>
  </tbody>
</table>

🟠 7. Interactive Forms & Inputs

Forms gather user input and submit it to a server. Always associate an <input> with a <label> using matching id and for attributes.

<form action="/submit-lead" method="POST">
    <div class="form-group">
        <label for="username">Full Name:</label>
        <input type="text" id="username" name="name" placeholder="Amara Chen" required>
    </div>

    <div class="form-group">
        <label for="email">Work Email:</label>
        <input type="email" id="email" name="email" required>
    </div>

    <div class="form-group">
        <label for="track">Learning Track:</label>
        <select id="track" name="track">
            <option value="web">Web Development</option>
            <option value="mobile">Mobile Apps</option>
            <option value="backend">Backend & Databases</option>
        </select>
    </div>

    <button type="submit">Enroll Now</button>
</form>

🟠 8. Semantic Layout Elements (HTML5)

Avoid the trap of "div soup" (wrapping everything in uninformative <div> containers). Modern HTML provides semantic landmark tags that give immediate architectural meaning:

<header> & <nav>

Header holds page branding, search, and introductory content. Nav wraps top-level navigation links.

<main> & <section>

Main is the unique central content of the document. Section groups thematic related material.

<article> & <footer>

Article represents a standalone piece of content (blog, card). Footer houses legal, copyright, and secondary links.

🟠 9. Metadata, Head, & Search Engine Optimization

The <head> section communicates directly with browsers, search crawlers, and social media share bots.

<!-- Page Title (Crucial for SEO) -->
<title>Learn HTML5 & CSS3 — CodePath Interactive Course</title>

<!-- Meta Description for Search Engine Snippets -->
<meta name="description" content="Step-by-step master class on HTML5 semantic architecture and modern web standards.">

<!-- OpenGraph tags for rich social media cards -->
<meta property="og:title" content="HTML5 for Beginners">
<meta property="og:image" content="https://example.com/preview.png">
<meta property="og:type" content="article">

🟠 10. Self-Check & Practice Checklist

Test your understanding of modern HTML5 before moving on to CSS:

  • ☑ I understand the difference between HTML, CSS, and JavaScript.
  • ☑ I can build an HTML5 boilerplate from memory.
  • ☑ I know why there should only be one <h1> on a page.
  • ☑ I always include alt attributes on <img> tags.
  • ☑ I know how to connect form inputs with matching labels.
  • ☑ I can build responsive layouts with semantic tags (<header>, <nav>, <main>, <footer>).
  • ☑ I can link multiple HTML documents using relative file paths.
